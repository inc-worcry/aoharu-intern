# aoharu-intern.worcry.com/long-intern/ 配信ソース（Xserver）

本番LP（Xserver）の配信元。`site/long-intern/` を編集して push すると、
GitHub Actions が FTP で Xserver へ自動反映します。

- 反映先: `/worcry.com/public_html/aoharu-intern.worcry.com/long-intern/`
- 公開URL: https://aoharu-intern.worcry.com/long-intern/
- 必要な Secrets: `FTP_SERVER` / `FTP_USERNAME` / `FTP_PASSWORD`
